CASE STUDY & SYSTEM OVERVIEW Sistem Informasi Permintaan Material Packaging

Ringkasan Proyek

Sistem berbasis web yang dirancang untuk mengelola dan memantau proses permintaan material packaging secara digital di lingkungan FMCG manufacturing. Sistem ini mengotomatiskan alur dari pengajuan oleh Unit Head, verifikasi oleh Checker GDTP, hingga rekapitulasi data dan export laporan oleh Admin guna meminimalkan selisih stok fisik dengan sistem enterprise (SAP).

Dokumentasi & Antarmuka Sistem

Autentikasi & Multi-Role Access Pintu masuk login aman berbasis sesi dan tingkatan hak akses pengguna.
Dashboard Ringkasan Panel metrik status BON masuk, permintaan diproses, dan ketersediaan stok.
Form Pengajuan BON Digital Formulir dinamis untuk input permintaan material per line dan nomor batch produksi.
Detail & Alur Approval Permintaan Rincian verifikasi item material packaging yang diajukan beserta status persetujuan.
Modul Mapping SKU Sinkronisasi dan pemetaan kode material terhadap varian produk jadi.
Master Data Material Database terpusat untuk katalog barang, unit pengukuran, dan kontrol stok.

Fitur & Alur Sistem

  • Pengajuan BON Digital: Penginputan permintaan material terstruktur berdasarkan jadwal rencana produksi harian (PPIC).
  • Verifikasi & Approval: Alur validasi bertingkat sebelum material dikeluarkan dari area transit/gudang.
  • Monitoring Stok Real-time: Pelacakan ketersediaan master material packaging per SKU dan nomor batch.
  • Role & Hak Akses: Pemisahan otoritas untuk Admin, Unit Head, dan Checker GDTP.
  • Export & Rekapitulasi: Pembuatan laporan pemakaian material dalam format siap cetak/PDF.

Teknologi yang Digunakan

PHP (Native & OOP) CodeIgniter 3 (MVC Architecture) MySQL Database Bootstrap & Custom CSS JavaScript (AJAX & DOM)
WEB APPLICATION

Sistem Informasi Penerimaan Mahasiswa Baru (PMB Online)

Web-based Admission & Student Enrollment System

1. Portal Login & Akun Pendaftar
2. Formulir Registrasi & Pilihan Prodi
3. Portal Unggah Dokumen & Pembayaran
4. Panel Admin & Verifikasi Seleksi

Tentang Proyek

Aplikasi web komprehensif yang dirancang untuk mendigitalkan seluruh rangkaian seleksi masuk perguruan tinggi, mulai dari pendaftaran mandiri calon mahasiswa, pemilihan program studi, pengunggahan dokumen berkas, validasi pembayaran, hingga panel verifikasi data oleh panitia PMB.

Fitur Utama

  • Autentikasi Multi-Level: Hak akses terpisah untuk Pendaftar / Calon Mahasiswa dan Administrator / Panitia PMB.
  • Formulir Registrasi Online: Input biodata lengkap, jalur seleksi (Reguler, Beasiswa, Prestasi), dan program studi pilihan.
  • Unggah Dokumen Digital: Upload berkas persyaratan (KTP, Ijazah, SKHUN, Pas Foto) dengan validasi format dan ukuran file.
  • Konfirmasi Pembayaran: Form pelaporan transaksi bank dan bukti bayar pendaftaran.
  • Panel Verifikasi Panitia: Master data pendaftar, aksi verifikasi berkas, persetujuan status seleksi, dan fitur ekspor rekapitulasi data (CSV).

Teknologi yang Digunakan

CodeIgniter 3 PHP MySQL Bootstrap
DATABASE & APPLICATION OVERVIEW Web Database & Book Management System

Ringkasan Proyek

Aplikasi berbasis web untuk pengelolaan katalog buku, kategori pustaka, dan transaksi sirkulasi peminjaman. Sistem ini menitikberatkan pada optimasi integritas data relasional antar-tabel serta kemudahan manajemen operasi CRUD (Create, Read, Update, Delete) secara efisien.

Fitur & Modul Utama

  • Katalogisasi & Master Data: Pengelolaan data buku, penerbit, pengarang, dan kategori rak.
  • Sirkulasi Peminjaman: Pencatatan peminjaman, batas tanggal pengembalian, dan kalkulasi denda keterlambatan.
  • Pencarian & Filtering: Filter data buku secara instan berdasarkan judul, ISBN, atau kategori topik.
  • Integritas Database: Relasi foreign key yang aman untuk mencegah *orphaned records* saat terjadi penghapusan data.

Teknologi yang Digunakan

PHP CodeIgniter 3 MySQL / MariaDB phpMyAdmin Database Designer HTML5 / CSS3
